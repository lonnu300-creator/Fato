# فرنوا پریمیوم 0.2.0

این نسخه یک بازطراحی موبایل‌محور از پیش‌نمایش فرنوا است.

## تغییرات مهم
- دکمه‌ها و آیکون‌ها بزرگ‌تر و مناسب لمس با انگشت
- ساختار مرتب‌تر برای موبایل
- داشبورد با نمودار فروش و هزینه
- فاکتور با خروجی‌های PDF/Print، Word، PNG و JPG
- انتخاب اندازه خروجی: A4 / A5 / 80mm
- بکاپ فایل‌محور با پسوند `.farnava`
- افکت صدای سبک و انیمیشن‌های نرم
- ذخیره‌سازی محلی بدون سرور

## تست سریع
- برای اجرای محلی: `npm install` سپس `npm start`
- برای اندروید: از GitHub Actions موجود در `.github/workflows/android-debug.yml` استفاده کن.

## نکته
این نسخه برای تست شخصی است و پرداخت بازار داخل آن فعال نشده است.
